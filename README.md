# AdminShop

PaperMC サーバー向けの、管理者が無限在庫で商品を売るショップ プラグインです。

プレイヤー同士の店（QuickShop）やオークション（AuctionHouse）とは別に、運営が直接売る枠を用意します。
通常商品は7つです。最後の死亡地点へ戻る「帰還の護符」、死んだときに手持ちの一部を守る「身代わりの護符」、生き物を丸ごと運べる「運搬の卵」と、サーバー全体に一定時間だけ効く
「豊穣の鐘」「鉱脈の号鐘」「疾風の笛」があります。建築用のMHFヘッド42種類も販売します。

## 装飾ヘッド（各50S）

`/shop` の「装飾ヘッド」から42種類を1画面で選び、確認画面を経て購入できます。
ブタ・ウシなどの生き物、チェスト・ケーキなどの小物、矢印や記号があります。
すべてプレイヤーヘッドなので、通常の頭と同じように設置できます。

種類と見た目はJAR内の `heads.yml` に固定しています。2026-09-23にMojangの公開プロフィールから取得した
テクスチャを保存しており、購入時にMHFアカウントを照会しません。購入ログの商品IDは `MHF_Pig` のような名前です。
共通価格は `config.yml` の `heads.price` で変更できます。既存の設定にこの項目がなくても50Sになります。

## 動作環境

- Minecraft サーバー: PaperMC 26.1.2〜26.3
- 対象 API: Paper API `1.21-R0.1-SNAPSHOT`
- Java: 21
- ビルドツール: Maven
- メインクラス: `dev.spa.adminshop.AdminShopPlugin`
- 必須プラグイン: Vault（経済プラグインは EssentialsX を想定）

## 商品：帰還の護符（250S）

メインハンドに持って右クリックすると、使った本人の最後の死亡地点付近へ戻る使い切りアイテムです。
死亡後に `/shop` で購入しても使えます。譲渡した場合も、使用者本人の死亡地点が対象です。

- 死亡地点の各軸±8ブロック以内で、足元と頭上が空いている足場を探します。溶岩・炎などの隣は避けます
- 別ワールドへの移動も可能です。安全な足場がない、ワールドが利用できない、他プラグインが移動を止めた場合は消費しません
- 移動成功で1個消費します。落としたアイテムの回収や、敵からの保護を保証するものではありません
- 導入後の死亡を `plugins/AdminShop/deaths.yml` に記録します。再ログイン・再起動後も残り、次の死亡で上書きします
- 使用しても記録は残ります。再使用するには別の護符が必要です

商品ID・効果IDは `return_charm`。管理者は `/ashop give <プレイヤー> return_charm` でも渡せます。
EcoLifeAssistの14マス目は公開メソッド `AdminShopPlugin#createRewardItem("return_charm")` から、購入時と同じ効果データを持つ護符を1個受け取ります。AdminShop停止中または商品が未登録なら `null` を返し、EcoLifeAssistはその日の受け取りを保留します。
既存設定には初回の起動時に空き枠へ商品を追加します（16番を優先）。空き枠がない場合は警告を出すため、
ショップを広げて `config.yml` に商品を追加してください。価格や表示位置は `items.return_charm` で変更できます。

## 商品：身代わりの護符（750S）

死亡したとき、**防具4枠・左手・ホットバー9枠の合計14枠**の中身だけを手元に残します。

- 持ち物の中に入れておくだけで働きます。手に持つ必要も、事前の準備も要りません
- 発動すると護符は1個消え、あとには何も残りません
- 守るのは上の14枠だけです。それ以外の持ち物と経験値は通常どおり失います
- 複数持っていても、1回の死亡で消えるのは1個だけです
- 他のプレイヤーへ渡せます。オークションにも出せます
- プレイヤーに殺された場合も発動します（`config.yml` で変えられます）

護符かどうかは、アイテムに埋め込んだデータ（PersistentDataContainer）だけで判定します。
金床で同じ名前を付けただけの偽物は護符として扱いません。

素材に不死のトーテムを使っていないのは、手に持っているとバニラの復活効果が先に働き、
そもそも死なないために護符が発動しない、という分かりにくい挙動になるためです。

### 「持っている」の範囲

発動を判定するのは、プレイヤーの持ち物欄（41枠）の中だけです。ホットバー・持ち物欄・防具・左手の
どこに入っていても発動します。

一方、次の場所に入れた護符は**発動しません**。どれも死亡時に持ち物欄として扱われない場所です。

- エンダーチェストの中
- シュルカーボックスやチェストなど、他の入れ物の中
- 馬やラマの荷物の中

### 発動しない場合

- ゲームルールや他プラグインが既に「死んでも全部残す」と決めているとき
- 護符に消滅の呪いが付いていて、死亡時に落ちる物の中に現れないとき

## 商品：運搬の卵（300S）

村人やペットを、ステータスごと卵に入れて運べる使い切りアイテムです。買えるのは空の卵で、生き物へ右クリックすると
「中身入りの卵」に変わります。中身入りの卵を地面へ右クリックすると、同じ子が出てきて卵は1個消えます。

- 中身はPaperのエンティティ保存（NBT）をそのまま持たせます。村人の職業・レベル・取引（使用回数・経験値含む）・噂、
  ペットの名前・首輪の色・飼い主・座り状態・体力、馬の鞍・防具・荷物などが丸ごと引き継がれます
- 対象は村人・行商人・ペット・家畜（Animals）です。敵対モブ、プレイヤー、案内係NPC、AIを止めた生き物は入れられません
- 他人が飼っているペットは入れられません。他人のGriefPrevention土地にいる生き物も、コンテナ信頼がなければ入れられません。
  出すときは、その場所の建築信頼が必要です
- 誰かが乗っている、リードにつながれている、取引中の生き物は入れられません
- 中身が大きすぎる場合（荷物を詰めたロバなど）は入れられません。上限は `perk-options.max-bytes`（既定65536）です
- `perk-options.blocked-worlds`（既定は `lobby`）のワールドでは、入れるのも出すのも止めます
- 出す場所に生き物の身長ぶんの空きがなければ断り、卵は残ります
- 中身入りの卵は1個ずつしか持てません。他のプレイヤーへの譲渡・オークションへの出品ができます
- 落としても燃えたり消えたりせず、時間で消滅もしません
- 入れる・出す操作はサーバーログに `[運搬の卵]` として残ります

商品ID・効果IDは `capture_egg`。中身入りの卵の効果IDは `capture_egg_filled` で、ショップでは売りません。
素材は `SNIFFER_EGG` です。バニラのスポーンエッグは使わないため、中身入りの卵をうっかり使っても新しい生き物は湧きません。

GriefPreventionは依存に加えず、入っている場合だけリフレクションで土地の権限を確かめます。呼び出しに失敗したときは許可しません。

## サーバー全体に効く3つの商品

豊穣の鐘・鉱脈の号鐘・疾風の笛は、どれも同じ形をしています。

- どれもアイテム型です。持ち物に入れておき、右クリックで使うと消えます
- 効果は**サーバー全体**に及びます。使った本人以外も得をします
- 時間は現実の時間で数えます。ログアウトしても、サーバーが再起動しても進みます
- 効果が続いている間に使うと、その分だけ延長します（既定の上限は種類ごとに合計120分）
- 効果中は全員のボスバーに残り時間が出ます。種類ごとに1本ずつ並びます
- 誰が使ったかはサーバー全体に流れます
- 他のプレイヤーへ渡せます。オークションにも出せます

### 使った人への上乗せ

鉱脈の号鐘と疾風の笛は、効果そのものは全員に及びますが、**使った人だけ1段階強くなります**。

上乗せを受けられるのは、その効果が続いている間に使った人**全員**です。最後に使った人だけを
優遇すると、先に買った人の取り分を後から来た人が奪う形になり、重ねがけを避ける動機が生まれて
しまうためです。効果が切れた時点で、この一覧は消えます。

豊穣の鐘には上乗せがありません。作物のイベントには「誰のものか」という
情報がないため、使った人のぶんだけを速くする判定ができないからです。

### 豊穣の鐘（750S）

右クリックで鳴らすと、**サーバー全体**の農作物の成長が **30分間だけ2倍**になります。
買った本人だけでなく、その時間に居合わせた全員の畑が早く育ちます。

ゲームルールの `randomTickSpeed` は使いません。あれはサーバー全体のあらゆるランダム更新を速めるため、
農作物だけでなく草の広がり・葉の枯れ・氷の融解まで巻き込み、負荷が跳ね上がります。

代わりに、作物が育つ瞬間に発生する `BlockGrowEvent` を拾い、成長段階を余分に1つ進めます。
サトウキビと苗木は、プレイヤーの近くで稼働しているチャンクに限り、自然のランダム更新を追加で試します。
他のブロックのランダム更新は増やしません。

対象は「成長段階」を持つブロック（小麦・ニンジン・ジャガイモ・ビートルート・ネザーウォート・カカオなど）と、
サトウキビ・苗木です。木とサトウキビは成長機会が2倍になり、実際に育つ時間にはばらつきがあります。
骨粉での成長は対象外です（プレイヤーの操作による成長で、`BlockGrowEvent` を通らないため）。

### 鉱脈の号鐘（1000S）

右クリックで鳴らすと、居合わせた全員に **30分間だけ採掘速度上昇 I** が付きます。
鳴らした人は **II** になります。

効果はポーション効果として毎秒かけ直します。効果中に参加した人や、死んで復活した人にも同じように
効かせるためです。自分で飲んだ強いポーションを上書きする心配は要りません。バニラは弱い効果で
強い効果を置き換えず、いったん隠して後で戻す作りになっています。

採掘速度上昇は**伐採と整地も同じだけ速くします**。地形が変わる速さも上がる点に注意してください。

### 疾風の笛（500S）

右クリックで吹くと、居合わせた全員に **20分間だけ移動速度上昇 I** が付きます。
吹いた人は **II** になり、あわせて落下ダメージを和らげる効果（低速落下）も付きます。

移動速度上昇は逃走と追跡の有利不利を作ります。全員に等しく配るため実害は薄いはずですが、
PvP を開けているサーバーではこの商品を置くかどうかを先に判断してください。

## コマンド

| コマンド | 権限 | 説明 |
| --- | --- | --- |
| `/shop` | `adminshop.use`（既定: 全員） | ショップを開く |
| `/ashop give <プレイヤー> <商品ID> [個数]` | `adminshop.admin`（既定: OP） | 商品を直接渡す |
| `/ashop reload` | `adminshop.admin` | `config.yml` を読み込み直す |

運搬の卵には次の権限があります。

| 権限 | 既定 | 説明 |
| --- | --- | --- |
| `adminshop.capture` | 全員 | 運搬の卵を使う |
| `adminshop.capture.bypass` | OP | 他人のペットや他人の土地の生き物にも使える |

`/shop` は `/adminshop` でも実行できます。

## 設定

`plugins/AdminShop/config.yml` で、価格・保護する範囲・商品の見た目を変えられます。

商品の追加は `items` にキーを足すだけですが、`perk`（効果の種類）は Java 側の実装が必要です。
未実装の `perk` を書いた商品は起動時に警告を出して読み飛ばします。実装済みなのは
`return_charm`・`keepsake_charm`・`capture_egg`・`growth_boost`・`mining_boost`・`speed_boost` の6つです。

サーバー全体に効く3つの商品に共通する設定は `boosts` にまとめてあります。重ねがけの上限
`max-total-minutes` は種類ごとに別々に数えます。豊穣の鐘しかなかった頃の `growth-boost` の
書き方も引き続き読めるため、古い `config.yml` をそのまま置いていても動きます。

### 週ごとの値上がり

`price-escalation.items` に並べた商品は、同じ人が同じ週に買うほど値上がりします。
既定の対象は身代わりの護符・帰還の護符・運搬の卵で、その週の1個目は定価、2個目は1.5倍、
3個目以降は2倍です（`multipliers`）。毎週月曜4:00（`reset-day`・`reset-hour`）に全員の個数が0に戻ります。

- ショップの値札には、その人が次に買うときの価格が出ます。値上がり中は定価と、定価へ戻る日時も出ます
- 数えるのはショップでの購入だけです。`/ashop give` や他プラグインの報酬は数えません
- 個数は `plugins/AdminShop/escalation.yml` に残り、再起動しても引き継ぎます
- `price-escalation` がない設定では、すべての商品が定価のままです

### 価格の考え方

2026-09-22に購入しやすさを優先して6商品を値下げしました。効果と持続時間は変更していません。
Jobs Reborn の収入上限 `1000+500*(合計レベル/100)` は、実際の平均時給とは異なります。
購入人数・商品別の購入数・通貨回収額を購入ログで確認し、価格を見直します。

既存サーバーの設定はJARの差し替えだけでは更新されません。
SPSMCではインフラの `plugins/AdminShop/config.yml` を正本として管理し、起動時に同期します。
価格変更時はこのリポジトリの既定値とインフラの設定を両方更新してください。

## 怪しいお薬

100Sで買える飲用ポーションです。飲み終わると1個消え、本人にバニラの持続効果が1種類付く。
28種類を等確率で抽選し、強さはレベルI〜III、持続時間は60〜300秒をそれぞれ等確率で選びます。
毒・衰弱・浮遊などの悪い効果も含み、レベルによる挙動はバニラと同じです。
瞬間効果、襲撃や試練の予兆、生物を出す効果は抽選しません。
通常のポーションや、他プラグインが飲用をキャンセルした場合には介入しません。
左右どちらの手からも飲め、クリエイティブでも1個消費します。空き瓶は残りません。
同じ種類の既存効果との重なりはバニラの処理に従います。
専用テクスチャは`adminshop:mystery_medicine`のitem modelで識別します。通常のポーションには付けません。
Java版の共通パックと統合版の専用パックは、隣接する`mc-ecolife`の`scripts/build-phone-packs.py`で生成します。
透過PNGと生成プロンプトは同リポジトリの`assets/adminshop/`で管理します。

## 記録

購入と発動を `plugins/AdminShop/` の下に1行1件のJSON（JSON Lines）で追記します。

- `purchases.log` — 誰がいつ何をいくらで買ったか
- `activations.log` — 護符の発動と、怪しいお薬の抽選結果（効果・レベル・秒数・適用結果）
- `boosts.log` — 誰がいつどの効果を何分ぶん発動させ、いつまで続くか

`purchases.log` の `price` は実際に支払った額で、週ごとの値上がりを含みます。

返金の相談や、護符が本当に働いたかの確認に使います。書き込みに失敗しても、警告を出すだけで
ゲーム側の動作は止めません。

## ローカルでの動作確認

```
./scripts/test-plugin.sh
python3 scripts/test-head-paper.py
python3 scripts/test-capture-egg.py
python3 scripts/test-mystery-medicine.py
```

`server-data-26.1.2/` に Paper のテストサーバーを立て、AdminShop が有効になるところまでを確認します。
装飾ヘッドのテストは `target/head-paper-smoke/` の隔離Paperで42種類の一覧・50S購入をテスト用Playerで検証します。
見た目、通常のクリック操作、設置、死亡時の保護は実際のクライアントでも確認してください。

怪しいお薬のテストは `target/medicine-paper-smoke/` の隔離Paperで、設定・2万回の抽選・
両手での1個消費・最後の1個の消滅・通常ポーションとキャンセル済み飲用への非介入を検証します。
飲む操作と表示はJava版・Bedrock版の実クライアントでも確認してください。

運搬の卵のテストは `target/capture-egg-smoke/` の隔離Paper（フラット世界）で、テスト用Playerから実イベントを流します。
村人の取引・職業・経験値、狼の飼い主・首輪・座り状態、馬の鞍・跳躍力の引き継ぎと、他人のペット・敵対モブ・案内係・狭い場所の拒否を確認します。
実クライアントでは、村人を運んで取引内容が変わっていないこと、GriefPreventionの他人の土地で拒否されること、Bedrock版でも操作できることを確認してください。

帰還の護符は次のケースも確認してください。

- 死亡後に購入し、右クリックで戻って1個だけ減る。複数個所持・連打でも1移動につき1個になる
- 2回死亡すると新しい地点へ戻る。譲渡しても使用者本人の地点へ戻る
- ネザーなど別ワールドからの帰還、死亡後の再起動を挟んだ帰還
- 未死亡、足場のない奈落、広い溶岩、削除・未ロードのワールドでは消費しない
- 他プラグインによるテレポート拒否では護符が返る。空中とブロックの右クリックの両方で使える
- 身代わりの護符と併用しても死亡地点が更新され、保護の動作に影響しない
